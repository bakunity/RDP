# Changelog

## 0.1.0 — 2026-08-06

Первый проектный релиз:

- единый сервер Hermes RDP;
- одинаковый Windows-клиент для основного и дополнительных ПК;
- автоматическая выдача постоянных RDP-портов;
- одноразовые коды подключения;
- Telegram Multi-PC dashboard в одном сообщении;
- ON, OFF, RESTART и LIVE-метрики каждого компьютера;
- автоматическая установка FRP 0.70.1 с проверкой SHA-256;
- резервные копии, обновление, удаление и диагностика;
- CI для Python, Bash и PowerShell.
