# Hermes RDP v1.1.0

Крупный релиз: транспорт полностью переведён с FRP на системный OpenSSH.

## Главное

- `frps` и `frpc.exe` удалены из текущей архитектуры;
- Windows использует встроенные `ssh.exe` и `ssh-keygen.exe`;
- отдельный Ed25519-ключ создаётся для каждого ПК;
- private key никогда не передаётся серверу;
- отдельный `sshd` на порту туннелей не предоставляет shell или SFTP;
- `permitlisten` ограничивает каждый ключ одним назначенным RDP-портом;
- SSH host key доставляется через pinned HTTPS и сохраняется в отдельном `known_hosts`;
- OFF и DELETE немедленно закрывают активный listener;
- удаление устройства освобождает порт для повторного использования;
- pairing и регистрация стали атомарными, поэтому ошибка не оставляет использованный код без устройства;
- установщик Windows больше не требует Defender exclusions.

## Миграция

Переход с `v1.0.x` выполняется серверным установщиком с `--migrate`. Старые устройства необходимо добавить заново, чтобы они получили индивидуальные SSH keys.

## Проверки

- Python unit tests для pairing, key validation, authorization, revoke и port reuse;
- статические architecture tests запрещают возврат FRP в текущие installer/agent файлы;
- Windows PowerShell 5.1 parsing и runtime certificate-pinning test;
- полный Linux release check.
