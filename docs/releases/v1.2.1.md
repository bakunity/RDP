# Hermes RDP v1.2.1 — Recommended stabilization release

`v1.2.1` — рекомендуемый stable release линии `v1.2.x`: полный согласованный tree большой stabilization-работы + исправление release-packaging ошибки `v1.2.0`.

Между `v1.1.0` и полным `v1.2.1` — **283 commit'а** с изменениями Windows Agent/installer/update/repair, Linux controller/API/DB/tunnel, Telegram UX, документации, сайта, release automation и regression/soak tests.

## Главное

- Windows/Linux reboot и reconnect recovery;
- multi-device режим и one-device failure isolation;
- transactional server + Windows update с automatic rollback;
- Repair существующего клиента без re-pair/rekey;
- Win10 x64 + 32-bit PowerShell через `Sysnative`;
- Windows Server 2019 support;
- исправлены stalled TLS API, OFF/ON reconciliation deadlock и stale command state;
- устранены RDP micro-freeze из telemetry fast path;
- Telegram OFF/ON/RESTART, auto-refresh, mobile UX, Repair и new pairing code;
- сохранена per-device Ed25519 security model без Defender exclusions.

## Проверено live

- external Microsoft RDP;
- Windows + Linux reboot recovery;
- несколько независимых Windows devices одновременно;
- two-session RDP + failure isolation;
- server/client update success + forced rollback;
- Repair success + rollback;
- Defender coexistence;
- Win10 x86 PowerShell/Sysnative и Windows Server 2019.

## Почему не v1.2.0

`v1.2.0` был опубликован не на полном validated release tree из-за ошибки release workflow. Исторический tag не переписывался; `v1.2.1` содержит полный согласованный snapshot этой stabilization baseline.
