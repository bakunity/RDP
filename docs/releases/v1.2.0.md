# Hermes RDP v1.2.0 — Stabilization

Большой стабилизационный релиз после перехода Hermes RDP на системный OpenSSH.

> **Важно:** исторический tag `v1.2.0` был опубликован с release-packaging ошибкой и не содержит полный финальный tree. Для install/update используйте **`v1.2.1`**.

## Главное

- добавлен **Repair существующего Windows-клиента** без fresh pairing и смены identity;
- server и Windows update стали **transactional** с backup, health-check и automatic rollback;
- исправлена работа **Windows 10 x64 из 32-bit PowerShell** через `Sysnative` + native OpenSSH;
- добавлена и live-проверена поддержка **Windows Server 2019**;
- закрыты soak-time проблемы: stalled TLS API, OFF/ON reconciliation deadlock и stale pending commands;
- устранены заметные **RDP micro-freeze** из-за тяжёлого telemetry fast path;
- подтверждены multi-device режим, failure isolation, reboot/reconnect recovery и безопасный port reuse;
- Telegram получил auto-refresh состояния, улучшенный mobile layout, **Repair** и **Новый код**.

## Проверено

- external Microsoft RDP;
- Windows + Linux reboot recovery;
- несколько Windows-ПК и два RDP-сеанса одновременно;
- one-device failure isolation;
- server/client update success + rollback;
- Repair success + rollback;
- Defender real-time coexistence;
- Windows 10 x64/x86 PowerShell и Windows Server 2019.

Также существенно обновлены README, Architecture, install/operations/security/troubleshooting docs, Testing A-to-Z, validated scenarios, public site и regression/soak tests.
