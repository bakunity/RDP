# Hermes RDP v1.3.0 — Trusted RDP certificates

Hermes RDP v1.3.0 добавляет полноценный trusted-certificate lifecycle для Windows RDP listener: от получения публичного IP-сертификата на Hermes server до автоматической установки, проверки и ротации на Windows.

## Главное

- опциональный Let’s Encrypt short-lived certificate для публичного IPv4 Hermes server;
- Hermes-owned renewal service/timer и non-secret certificate state;
- authenticated доставка certificate package только зарегистрированному Windows device;
- отдельный LocalSystem rotation worker вне основного 3-секундного Agent loop;
- автоматический CUSTOM certificate binding Windows `RDP-Tcp` и восстановление после local drift;
- Fresh Install, transactional Update и Repair автоматически управляют certificate companion из одного immutable source SHA;
- normal Uninstall удаляет основной Agent и certificate-rotation runtime;
- исправлен rollback между default Windows self-signed state и explicit CUSTOM binding;
- сохранены Windows PowerShell 5.1, Win10 x64/x86 Sysnative compatibility и Defender coexistence без exclusions;
- README, public site, operations/security docs и release-history workflow синхронизированы с принятым behavior.

## Проверено

- production public-IP certificate issuance, chain/key validation и renewal smoke;
- реальный внешний Microsoft Remote Desktop с trusted certificate без прежнего self-signed warning;
- automatic recovery после controlled listener drift;
- live Update и Repair с сохранением device identity, keys, `known_hosts` и RDP port;
- чистый Windows 10 Pro / PowerShell 5.1 / Defender-enabled Fresh Install и normal Uninstall;
- Linux full release checks и Windows PowerShell 5.1 CI.

## Breaking changes / recommendation

Breaking changes относительно `v1.2.1` не вводятся. Trusted RDP certificate lifecycle опционален; для него нужен глобально маршрутизируемый public IPv4 и доступный TCP `80` для ACME HTTP-01.

После публикации `v1.3.0` рекомендуется для новых install/update вместо `v1.2.1`.
