# Hermes RDP v1.2.1 — Release packaging hotfix

Release: https://github.com/bakunity/RDP/releases/tag/v1.2.1

`v1.2.1` исправляет ошибку публикации `v1.2.0`: release workflow создал тег на первом commit, изменившем `VERSION`, а не на полном проверенном release tree. Из-за этого опубликованный `v1.2.0` tag содержал неполные release metadata и старый README, хотя merge в `main` был корректным.

## Что исправлено

- опубликованный release tree снова содержит согласованные `VERSION`, package `__version__` и `pyproject.toml`;
- в tag входит полный product README с badges, архитектурой, quick start, update/repair и security sections;
- release notes и CHANGELOG входят в тот же immutable release tree;
- runtime-функциональность остаётся той же live-accepted stabilization baseline, что была подготовлена для `v1.2.0`.

## Breaking changes

Нет намеренных breaking changes относительно `v1.1.0`/подготовленного `v1.2.0` runtime.

## Рекомендация

Для установки и обновления используйте `v1.2.1`, а не `v1.2.0`.

Подробный acceptance: [../VALIDATED_SCENARIOS.md](../VALIDATED_SCENARIOS.md).
