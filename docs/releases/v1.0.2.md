# Hermes RDP v1.0.2

Hotfix стабильного серверного установщика.

## Исправлено

В `v1.0.1` скачанный `install-server.sh` пытался получить полный архив проекта по адресу для Git-веток:

```text
archive/refs/heads/v1.0.1.tar.gz
```

Поскольку `v1.0.1` является тегом, GitHub возвращал HTTP 404 до создания конфигурации и запуска сервисов.

В `v1.0.2` используется универсальная загрузка через `codeload.github.com`, которая одинаково поддерживает стабильные теги и ветки разработки.

## Совместимость

- серверный API и Windows agent обратно совместимы с `v1.0.1`;
- схема SQLite и pairing contract не изменены;
- стандартные порты не изменены;
- повторный запуск после ранней ошибки `v1.0.1` безопасен на чистом сервере.
