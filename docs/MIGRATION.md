# Миграция существующего Hermes RDP

Миграция переводит прежнюю одно-компьютерную схему в общий реестр устройств. Первый Windows-компьютер не получает специальной роли и после подключения обслуживается тем же агентом, что и все последующие ПК.

## 1. Резервная копия

Серверный установщик сам создаёт резервную копию в `/var/backups/hermes-rdp/<timestamp>`, но перед миграцией также рекомендуется сохранить текущие каталоги FRP и бота.

## 2. Установить серверную часть

```bash
curl -fsSL https://raw.githubusercontent.com/bakunity/RDP/main/scripts/install-server.sh | sudo bash
```

Установщик пытается импортировать существующий FRP token и совместимые TLS-файлы. Текущий порт `53389` можно сохранить за первым устройством.

## 3. Создать код для первого ПК

```bash
sudo hermes-rdpctl pair create --name 'Домашний ПК' --port 53389
```

Скопировать выданные команду и SHA-256 fingerprint сертификата API.

## 4. Установить единый Windows-клиент

Запустить выданную команду в PowerShell от имени администратора. Установщик удалит старые задачи Hermes FRPC/Windows Monitor после успешной регистрации нового агента.

## 5. Проверить

```bash
sudo hermes-rdpctl devices list
sudo systemctl status frps hermes-rdp --no-pager
```

В Telegram отправить `/start`. Должен появиться список устройств, где первый ПК отображается как `Домашний ПК` с портом `53389`.
