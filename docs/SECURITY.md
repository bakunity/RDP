# Безопасность

## Реализовано

- HTTPS API использует TLS 1.2+;
- установщик проверяет точный SHA-256 fingerprint сертификата;
- pair code одноразовый и ограничен по времени;
- у каждого устройства отдельный случайный API token;
- сервер хранит только SHA-256 токена;
- Telegram доступен только одному заданному user ID;
- Windows secrets имеют ограниченный ACL;
- FRP TLS проверяется собственной CA;
- systemd-сервисы запускаются от непривилегированных пользователей;
- установщик FRP проверяет официальный SHA-256 архива.

## Ограничение общего FRP token

FRP token общий для всех устройств. Это ограничение текущей схемы FRP token auth. При компрометации одного Windows-клиента:

1. удали устройство из Telegram;
2. замени `/etc/hermes-rdp/frp-token`;
3. обнови `/etc/frp/frps.toml`;
4. перерегистрируй доверенные клиенты.

## Не публикуй

- Telegram bot token;
- `device.json`;
- `frpc.toml`;
- server backup;
- содержимое `/etc/hermes-rdp`.
