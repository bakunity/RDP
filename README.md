# Hermes RDP

Self-hosted система для управления удалённым доступом к нескольким Windows-компьютерам через один Linux-сервер и Telegram.

## Подтверждённый scope v1.2.0

Поддерживаются несколько Windows-компьютеров, восстановление после сбоев и перезагрузок, Telegram control, Windows 10/Server 2019, transactional update/rollback и отдельный Repair существующего клиента.
