# Hermes RDP v1.0.1

Дата выпуска: **6 августа 2026 года**

Документационный и privacy-патч для безопасного публичного развёртывания и полного тестирования Hermes RDP на отдельной инфраструктуре.

## Что изменилось

### Новый гайд от А до Я

Добавлен [полный сценарий тестирования](../TESTING_A_TO_Z.md), рассчитанный на:

- отдельный Linux-сервер;
- нового Telegram-бота;
- новый Windows-ПК;
- последующее добавление второго Windows-ПК.

Гайд включает:

1. подготовку сервера и Telegram;
2. безопасное использование переменных;
3. установку server-компонентов;
4. проверку `frps.service` и `hermes-rdp.service`;
5. проверку API и firewall;
6. регистрацию первого ПК с портом `53389`;
7. проверку Windows Scheduled Task и FRPC;
8. проверку Telegram LIVE-метрик;
9. реальное RDP-подключение;
10. тесты `ON`, `OFF` и `RESTART`;
11. перезагрузку Windows;
12. перезапуск controller и FRPS;
13. добавление второго ПК на `53390`;
14. независимость устройств;
15. удаление и отзыв устройства;
16. итоговый acceptance checklist.

## Privacy cleanup

Из публичных примеров удалены project-specific значения:

- реальные публичные IP;
- реальные machine names;
- реальные usernames;
- внешние client addresses;
- названия конкретных пользовательских ПК.

Вместо них используются переменные:

```text
SERVER_IP_OR_DOMAIN
TELEGRAM_BOT_TOKEN
TELEGRAM_USER_ID
WINDOWS-PC-01
WINDOWS_USER
CLIENT_IP_ADDRESS
PAIR_CODE
API_FINGERPRINT
```

Технические порты проекта сохранены:

```text
7000/tcp
7443/tcp
53389-53420/tcp
```

## Защита от повторной утечки

Добавлен scanner:

```text
scripts/check-public-examples.py
```

Он проверяет текстовые файлы и завершает CI ошибкой, если обнаруживает глобальный публичный IPv4 или IPv6 вместо:

- переменной;
- loopback/private address;
- специальной RFC documentation network.

Privacy scan включён в:

```bash
bash scripts/check-release.sh
```

## Совместимость

`v1.0.1` не меняет:

- API `/v1`;
- SQLite schema;
- pairing contract;
- формат `device.json`;
- формат `frpc.toml`;
- стандартные порты;
- Telegram callback contract;
- Windows telemetry format.

Server и Windows clients `v1.0.0` остаются совместимыми, но для новых установок рекомендуется `v1.0.1`.

## Установка тестового сервера

На Linux:

```bash
export HERMES_RDP_VERSION='v1.0.1'
export SERVER_HOST='SERVER_IP_OR_DOMAIN'
export TELEGRAM_USER_ID='123456789'
read -rsp 'Telegram bot token: ' TG_TOKEN; echo
```

```bash
curl -fsSL "https://raw.githubusercontent.com/bakunity/RDP/${HERMES_RDP_VERSION}/scripts/install-server.sh" -o /tmp/install-hermes-rdp.sh
```

```bash
sudo env HERMES_RDP_REF="$HERMES_RDP_VERSION" bash /tmp/install-hermes-rdp.sh \
  --host "$SERVER_HOST" \
  --telegram-token "$TG_TOKEN" \
  --telegram-chat-id "$TELEGRAM_USER_ID"
```

```bash
unset TG_TOKEN
rm -f /tmp/install-hermes-rdp.sh
sudo hermes-rdpctl doctor
```

## Подключение первого Windows-ПК

На сервере:

```bash
sudo hermes-rdpctl pair create --name 'Windows-PC-01' --port 53389
```

На Windows PowerShell от администратора:

```powershell
$Version = 'v1.0.1'
$Server = 'SERVER_IP_OR_DOMAIN'
$PairCode = 'PAIR_CODE'
$Fingerprint = 'API_FINGERPRINT'
$PcName = 'Windows-PC-01'
$InstallerUrl = "https://raw.githubusercontent.com/bakunity/RDP/$Version/scripts/install-client.ps1"
& ([scriptblock]::Create((irm $InstallerUrl))) -Server $Server -PairCode $PairCode -Fingerprint $Fingerprint -Name $PcName -RepositoryRef $Version
```

## Проверка

Server:

```bash
sudo hermes-rdpctl doctor
sudo systemctl status frps.service hermes-rdp.service --no-pager
sudo hermes-rdpctl devices list
```

Windows:

```powershell
Get-ScheduledTask -TaskName 'Hermes RDP Agent'
Get-ScheduledTaskInfo -TaskName 'Hermes RDP Agent'
Get-Content 'C:\ProgramData\HermesRDP\agent.log' -Tail 100
```

Endpoint с другого компьютера:

```powershell
Test-NetConnection SERVER_IP_OR_DOMAIN -Port 53389
mstsc.exe /v:SERVER_IP_OR_DOMAIN:53389
```

## Обновление с v1.0.0

Server:

```bash
curl -fsSL https://raw.githubusercontent.com/bakunity/RDP/v1.0.1/scripts/update-server.sh -o /tmp/update-hermes-rdp.sh
sudo env HERMES_RDP_REF=v1.0.1 bash /tmp/update-hermes-rdp.sh
rm -f /tmp/update-hermes-rdp.sh
```

Windows:

```powershell
$u='https://raw.githubusercontent.com/bakunity/RDP/v1.0.1/scripts/update-client.ps1'; & ([scriptblock]::Create((irm $u))) -RepositoryRef 'v1.0.1'
```
