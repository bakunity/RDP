Windows подключается к серверу сам

Домашнему или офисному роутеру не нужен проброс входящих портов. Windows инициирует исходящий OpenSSH-сеанс и поднимает reverse forwarding до локального RDP.

SECURITY BY DEFAULT

Ключи и контроль остаются у вас

Каждый ПК получает отдельный API-token, SSH-ключ и разрешение только на свой RDP-порт. Отдельный Hermes sshd не предоставляет shell или SFTP.

  • ✓
    HTTPS certificate pinningWindows проверяет SHA-256 сертификата API.
  • ✓
    SSH host key pinningКлюч сервера приходит через уже закреплённый HTTPS API.
  • ✓
    permitlistenPublic key может открыть только назначенный RDP endpoint.
  • ✓
    Trusted RDP listener TLSОпциональный public-IP certificate lifecycle отделён от API TLS и управляется автоматически.
  • ✓
    Отзыв устройстваDELETE отзывает token и key, закрывает listener и освобождает порт.
Важно: Hermes не заменяет Windows authentication. Используйте сильный уникальный пароль, NLA, обновления и ограничение источников в firewall там, где это возможно.

От чистого сервера до первого RDP

Stable release — v1.2.1. Возможности current main для следующего релиза используйте только с заранее проверенным immutable commit.

SERVER · BASH
# Stable release v1.2.1
curl -fsSL https://raw.githubusercontent.com/bakunity/RDP/v1.2.1/scripts/install-server.sh \
  -o /tmp/install-hermes-rdp.sh

read -rsp 'Telegram bot token: ' TG_TOKEN; echo
sudo env HERMES_RDP_REF=v1.2.1 bash /tmp/install-hermes-rdp.sh \
  --host SERVER_IP_OR_DOMAIN \
  --telegram-token "$TG_TOKEN" \
  --telegram-chat-id TELEGRAM_USER_ID
unset TG_TOKEN
# В Telegram
/start

FAQ

Частые вопросы

Границы текущей архитектуры без маркетинговых обещаний сверх принятого поведения.

Нужен ли белый IP на каждом Windows-ПК?＋

Нет. Публичный адрес нужен Linux-серверу. Windows инициирует исходящий OpenSSH-сеанс.

Можно ли подключить несколько компьютеров?＋

Да. Multi-device endpoints, одновременные RDP-сессии и failure isolation уже live-проверены.

Нужны ли исключения Microsoft Defender?＋

Нет. Hermes использует системные ssh.exe и ssh-keygen.exe; Defender coexistence проверен с real-time protection.

Что убирает предупреждение сертификата RDP?＋

Не HTTPS API certificate, а certificate самого Windows RDP listener. Current main умеет автоматически получать, доставлять, привязывать и ротировать trusted public-IP certificate.

Что сейчас stable?＋

Опубликованный stable release — v1.2.1. Current main уже содержит следующий принятый lifecycle trusted RDP certificate; до следующего release используйте его только с проверенным immutable commit.
