# Hermes RDP v1.2.0 — Stabilization

Release: https://github.com/bakunity/RDP/releases/tag/v1.2.0

`v1.2.0` focuses on reliability, compatibility and recovery.

Validated in this release:

- Windows 10 x64 and Windows Server 2019;
- reboot and reconnect recovery;
- multiple Windows computers at the same time;
- safer server/client updates with rollback;
- Repair for an existing registered client;
- Telegram Repair and new pairing-code actions.

No intentional breaking changes are introduced relative to `v1.1.0`.

Detailed validated scenarios are documented in `docs/VALIDATED_SCENARIOS.md`.
