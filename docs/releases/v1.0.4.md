# Hermes RDP v1.0.4

UX-патч Telegram-панели добавления Windows-ПК.

## Изменено

PowerShell-команда установки теперь выводится единым моноширинным блоком. В Telegram её можно скопировать целиком одним нажатием, без ручного выделения длинной строки.

Команда HTML-экранируется, поэтому специальные символы внутри URL и PowerShell не ломают разметку сообщения.

## Совместимость

- серверный API и Windows agent не изменены;
- схема SQLite и pairing contract не изменены;
- обновление затрагивает только Telegram UI;
- стандартные порты не изменены.
