# Contributing

1. Создавайте отдельную ветку от `main`.
2. Не добавляйте в репозиторий Telegram tokens, FRP tokens, приватные ключи, сертификаты с приватной частью или реальные device credentials.
3. Перед pull request выполните:

```bash
bash scripts/check-release.sh
```

4. Для изменений PowerShell убедитесь, что файл успешно разбирается Windows PowerShell 5.1.
5. Для изменений реестра устройств добавляйте или обновляйте тесты в `tests/`.
6. Описывайте влияние на миграцию, безопасность и обратную совместимость.
