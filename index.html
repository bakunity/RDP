От чистого сервера до первого RDP

Используйте стабильный тег релиза. Значения сервера, Telegram ID и pairing-кода подставляются при развёртывании.

SERVER · BASH 
# Скачать стабильный установщик
curl -fsSL https://raw.githubusercontent.com/bakunity/RDP/v1.0.4/scripts/install-server.sh \
  -o /tmp/install-hermes-rdp.sh

# Запустить установку
sudo env HERMES_RDP_REF=v1.0.4 bash /tmp/install-hermes-rdp.sh \
  --host SERVER_IP_OR_DOMAIN \
  --telegram-token "$TG_TOKEN" \
  --telegram-chat-id TELEGRAM_USER_ID
# Создать первый компьютер на стандартном порту
sudo hermes-rdpctl pair create \
  --name 'Windows-PC-01' \
  --port 53389

PAIR_CODE=XXXXXXXX
SERVER=SERVER_IP_OR_DOMAIN
FINGERPRINT=SHA256_HEX
# PowerShell от имени администратора
$u='https://raw.githubusercontent.com/bakunity/RDP/v1.0.4/scripts/install-client.ps1'
& ([scriptblock]::Create((irm $u))) \
  -Server 'SERVER_IP_OR_DOMAIN' \
  -PairCode 'PAIR_CODE' \
  -Fingerprint 'SHA256_HEX' \
  -Name 'Windows-PC-01' \
  -RepositoryRef 'v1.0.4'
# Проверка доступности
Test-NetConnection SERVER_IP_OR_DOMAIN -Port 53389

# Открыть Remote Desktop
mstsc.exe /v:SERVER_IP_OR_DOMAIN:53389

FAQ

Частые вопросы

Коротко о границах и принципах текущей версии.

Нужен ли белый IP на каждом Windows-ПК?＋

Нет. Публичный адрес требуется только Linux-серверу Hermes. Windows-клиенты устанавливают исходящие соединения с ним.

Первый компьютер отличается от остальных?＋

Нет. Все Windows-компьютеры равноправны и используют одинаковый установщик. Отличаются только device credentials и выделенный RDP-порт.

Можно ли сохранить привычный порт 53389?＋

Да. При создании pairing порт можно закрепить явно. Следующие устройства получат свободные порты из настроенного диапазона.

Данные проходят через сторонний облачный сервис?＋

Нет. Контроллер, FRP-сервер, API и реестр устройств работают на вашем Linux-сервере. Telegram используется как интерфейс управления.

Проект подходит для production?＋

Версия 1.0.4 является стабильной, но перед production-развёртыванием рекомендуется пройти полный гайд тестирования и изучить документ безопасности.
