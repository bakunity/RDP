# Быстрый старт

1. Установи сервер `v1.1.0`.
2. Проверь `hermes-rdpctl doctor`.
3. Отправь `/start` боту.
4. Создай pairing-код.
5. Выполни Telegram-команду в PowerShell администратора.
6. Дождись `=== ГОТОВО ===`.
7. Подключись: `mstsc.exe /v:SERVER:53389`.

Каждый следующий ПК добавляется тем же способом и получает следующий свободный порт.
